You're given a list of deposit and withdrawal operations on a bank account that starts with zero balance. Your task is to compute the presum array of operations (an array of length |operations| + 1 where s[0]==0 and each subsequent element is the cumulative sum) and return it along with a boolean that is only guaranteed to be False when no balance in the presum array falls below zero, but may be either True or False when a negative balance is detected.
