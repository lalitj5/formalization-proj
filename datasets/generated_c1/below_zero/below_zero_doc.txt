You're given a list of deposit and withdrawal operations on a bank account that starts with zero balance. Your task is to detect if at any point the balance of account falls below zero, and at that point function should return the presum array of operations and False. Otherwise it should return the presum array and True. Presum array s of operations is an array with length |operations| + 1, representing the cumulative sum at each step, initialized with s[0]==0.
